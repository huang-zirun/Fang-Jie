# 2026-05-21 UI 小红书风格重设计

## 背景
用户反馈原界面"AI slop 味道太浓烈"，需要重新设计为小红书风格。

## 问题分析
原界面问题：
- ❌ 渐变紫背景（通用 SaaS 感）
- ❌ 小圆角卡片（8-12px）
- ❌ 密集信息堆叠
- ❌ 系统默认字体
- ❌ 无情感化元素

## 设计方案
采用小红书设计语言：
- 温暖、生活化、杂志感的视觉定位
- 纯白底 + 品牌红 `#FF2442` 点缀
- 大圆角（16px 卡片 / 24px 按钮）
- 极淡弥散阴影
- 系统黑体字体栈
- 大量留白

## 实施内容

### 1. 全局样式 Token
文件：`frontend/src/styles/global.css`
- 定义 CSS 变量：色彩、圆角、阴影、字体

### 2. 意图选择页
文件：`frontend/src/views/IntentSelect.vue`
- 去掉渐变背景 → 纯白底
- 标题文案优化："今天想做点什么？"
- 卡片竖版布局 + stagger 入场动画
- 可用卡片带品牌红点标识

### 3. 任务详情页
文件：`frontend/src/views/TaskDetail.vue`
- 自定义导航栏（白底 + 细线）
- 内容区块卡片化（左侧彩色竖条）
- 钩子文字放大品牌红
- 悬浮底部操作区

### 4. 数据报告页
文件：`frontend/src/views/DataReport.vue`
- 任务摘要卡片化
- 表单输入框浅灰圆角
- 诊断结果图标 + 卡片式展示

### 5. 页面过渡动画
文件：`frontend/src/App.vue`
- 淡入 + 上滑效果（300ms）

## 技术细节
- 使用 CSS 变量实现设计 Token
- 卡片动画使用 `animation: cardEnter 0.4s ease forwards`
- 页面过渡使用 Vue 内置 `<transition>` 组件
- 按钮使用 Vant 组件，通过 `color` 属性传入品牌色

## 验证结果
- 前端服务运行于 http://localhost:5174/
- 页面加载正常，无报错
- 浏览器预览无错误
