# 抓取软科中国大学排名（2026）院校名单并输出 CSV

## 目标
- 抓取 `https://www.shanghairanking.cn/rankings/bcur/202611` 的院校排名数据
- 该页面共有 20 个子页面（分页）
- 最终输出为 CSV 文档

## 页面结构分析
- 页面为软科中国大学排名（主榜）
- 每页展示约 30 条院校数据
- 分页控件显示共 20 页
- 每条数据包含：排名、校徽、学校名称（中英文）、省份、类型、总分、标签（双一流/985/211等）

## 抓取策略
- 页面为动态渲染（SPA），静态 HTML 中不包含完整数据
- 需要分析网络请求，找到数据 API 接口
- 或使用浏览器自动化工具（Playwright / Selenium）模拟翻页抓取

## 实施步骤

### 步骤 1：分析数据接口
- 打开浏览器开发者工具，观察网络请求
- 寻找返回 JSON 数据的 API 接口（通常包含 `ranking` 或 `list` 等关键词）
- 记录接口 URL、请求参数、分页参数

### 步骤 2：编写抓取脚本
- 使用 Python + `requests` 或 `httpx` 调用 API 接口
- 遍历 1-20 页，获取所有院校数据
- 解析 JSON 响应，提取字段：排名、学校名称、英文名称、省份、类型、总分、标签

### 步骤 3：数据清洗与格式化
- 统一字段格式
- 处理缺失值
- 合并所有分页数据

### 步骤 4：输出 CSV
- 使用 `pandas` 或 `csv` 模块写入 CSV 文件
- 文件路径：`e:\系统文件夹\Desktop\Channing\Fang-Jie\shanghairanking_universities_2026.csv`

## 备选方案
- 如果无法直接获取 API，使用 Playwright 浏览器自动化：
  - 打开页面，等待数据加载
  - 循环点击分页按钮，提取每页 HTML 中的数据
  - 使用 BeautifulSoup 解析 HTML

## 字段定义（预期）
| 字段名 | 说明 |
|--------|------|
| rank | 排名 |
| name_cn | 学校中文名 |
| name_en | 学校英文名 |
| province | 省份 |
| category | 类型（综合/理工/师范等）|
| total_score | 总分 |
| tags | 标签（双一流/985/211）|

## 风险与注意事项
- 网站可能有反爬机制（频率限制、验证码）
- 需要控制请求频率，添加延时
- 数据接口可能变化，需要动态适配
