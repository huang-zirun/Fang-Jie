# 小红书风格 UI 重设计计划

## 1. 视觉定位

### 视觉主题（Visual Thesis）
温暖、生活化、杂志感的移动内容创作工具——像翻开一本精致的个人手账，而不是面对一个冷冰冰的 SaaS 仪表盘。

### 内容架构
- **首页（意图选择）**：温暖问候 + 目标卡片网格
- **任务页**：内容创作工作区——钩子、分镜、文案、标题、评论话术
- **数据页**：简洁的数据输入 + 诊断反馈

### 交互主张
- 页面切换使用淡入 + 轻微上滑，营造"翻页"感
- 卡片 hover/active 时有细腻的缩放和阴影变化
- 内容区块使用圆角大卡片，模拟实体卡片的堆叠感

---

## 2. 小红书设计语言分析

### 核心特征
| 维度 | 小红书风格 |
|------|-----------|
| 色彩 | 以白色/米白为底，品牌红（#FF2442）为点缀，低饱和辅助色 |
| 圆角 | 大圆角（12-20px），柔和无攻击性 |
| 阴影 | 极淡的弥散阴影，模拟纸张浮起 |
| 排版 | 标题用系统黑体加粗，正文用常规字重，行高宽松 |
| 间距 | 大量留白，模块之间呼吸感强 |
| 图标 | 线性图标，细线条，不抢视觉 |
| 图片 | 圆角封面图，真实生活场景 |

### 与当前界面对比问题
- ❌ 渐变紫背景（太像通用 SaaS）→ ✅ 纯白/米白底
- ❌ 小圆角卡片（8-12px）→ ✅ 大圆角（16-20px）
- ❌ 密集信息堆叠 → ✅ 模块分区，大量留白
- ❌ 系统默认字体 → ✅ 优先使用系统黑体（PingFang SC / Noto Sans SC）
- ❌ 无情感化元素 → ✅ 加入 emoji/插图作为视觉锚点

## 3. 设计系统 Token

### 色彩
```
--xh-bg-primary: #FFFFFF        /* 主背景 */
--xh-bg-secondary: #F7F7F7      /* 次级背景/卡片hover */
--xh-bg-tertiary: #F2F2F2       /* 输入框背景 */
--xh-brand: #FF2442             /* 小红书品牌红 */
--xh-brand-light: #FFF0F2       /* 品牌浅色背景 */
--xh-text-primary: #333333      /* 主标题 */
--xh-text-secondary: #666666    /* 正文 */
--xh-text-tertiary: #999999     /* 辅助文字 */
--xh-border: #EEEEEE            /* 分割线/边框 */
--xh-success: #07C160           /* 成功绿 */
--xh-warning: #FF9900           /* 警告橙 */
```

### 字体
```
font-family: -apple-system, BlinkMacSystemFont, 'PingFang SC', 'Noto Sans SC', 'Helvetica Neue', sans-serif;
```
- 大标题：22-24px, font-weight 700
- 模块标题：16-18px, font-weight 600
- 正文：14-15px, font-weight 400
- 辅助文字：12-13px, font-weight 400

### 圆角
```
--radius-card: 16px       /* 卡片 */
--radius-button: 24px     /* 按钮（全圆角胶囊） */
--radius-input: 12px      /* 输入框 */
--radius-tag: 8px         /* 标签 */
```

### 阴影
```
--shadow-card: 0 2px 12px rgba(0, 0, 0, 0.04);
--shadow-float: 0 4px 20px rgba(0, 0, 0, 0.08);
```

### 间距
- 页面边距：16px
- 卡片内边距：16-20px
- 模块间距：12-16px
- 元素间距：8-12px

## 4. 页面级设计

### 4.1 意图选择页（IntentSelect.vue）

#### 布局重构
- **顶部区域**：去掉渐变背景，改为纯白底 + 大标题左对齐
- 标题文案优化："今天想怎么赚钱？" → 更温暖的"今天想做点什么？"
- 副标题："选一个目标，给你今天的行动指南"
- **卡片网格**：2列，但卡片改为竖版（图标在上，文字在下）
- 卡片样式：白色底 + 大圆角(16px) + 淡阴影 + hover 微上浮
- 可用卡片：边框或左上角用品牌红点标识
- 不可用卡片：灰度处理，显示"即将开放"标签

#### 视觉细节
- 每个意图配一个精致的 emoji 图标（40px）
- 卡片内边距：24px 16px
- 卡片间距：12px
- 页面整体边距：16px

### 4.2 任务详情页（TaskDetail.vue）

#### 布局重构
- **顶部导航**：使用自定义导航栏，白色底 + 底部细线，标题居中
- **平台标签**：改为胶囊形标签，品牌色背景
- **内容区块**：每个 section 改为独立大卡片
  - 卡片标题：左侧加彩色竖条（4px宽，品牌色）
  - 卡片内容：充足的内边距
- **钩子文字**：放大显示（18px），使用品牌红色，加引号装饰
- **分镜脚本**：改为横向滑动卡片或纵向时间线样式
- **文案区域**：浅灰背景，等宽字体感，复制按钮放右上角
- **底部操作区**：悬浮底部，白色底 + 顶部细阴影
  - 主按钮：品牌红，全圆角胶囊
  - 次按钮：白色底 + 品牌红边框

#### 视觉细节
- 优化提示 banner：改为淡粉色背景 + 品牌红文字
- 原理说明：改为淡蓝色背景的信息卡片

### 4.3 数据报告页（DataReport.vue）

#### 布局重构
- **任务摘要卡片**：白色大卡片，显示标题 + 平台 + 日期
- **表单区域**：
  - 输入框改为圆角大输入框，浅灰背景
  - 标签左对齐，不使用 Vant 默认的 cell 样式
  - 提交按钮：品牌红，全宽胶囊
- **诊断结果**：
  - 改为卡片式展示，每个诊断项一个卡片
  - 使用图标 + 标题 + 内容的结构
  - 优化建议使用引用块样式

## 5. 动效规划

### 页面过渡
- 进入：opacity 0→1 + translateY(20px→0)，duration 300ms，ease-out
- 离开：opacity 1→0，duration 150ms

### 卡片交互
- hover：translateY(-2px) + shadow 加深，duration 200ms
- active/press：scale(0.98)，duration 100ms

### 内容加载
- 卡片 stagger 入场：每个卡片延迟 50ms
- 使用 opacity + translateY 组合

5. **添加页面过渡动画**
