# Checklist

## 闭环骨架

* [x] 项目结构初始化完成（frontend / backend / docker 三目录）

* [x] Docker Compose 可一键启动（FastAPI + PostgreSQL + Nginx）

* [x] 匿名注册 API 返回有效 JWT

* [x] 意图列表 API 返回 4 个意图，仅"引流拿客户" is_active=true

* [x] 前端首屏渲染 4 个意图按钮，灰显按钮不可点击

* [x] 点击"引流拿客户"后跳转到任务界面

* [x] 任务界面展示固定模板内容（钩子/分镜/口播/标题/话术）

* [x] 点击"我已发布"后任务状态变为 PUBLISHED

* [x] JWT 认证中间件正确拦截未认证请求

## 任务生成与结构库

* [x] content_structures 表至少有 6 条种子数据（4 抖音 + 2 小红书）

* [x] 按 intent_id + platform_id 可查询到匹配的结构模板

* [x] Claude API 调用封装支持超时（10s）和重试（1 次）

* [x] AI 生成的任务包含所有必需字段（hook_text, storyboard, script_text, title, comment_template, why_it_works）

* [x] AI 输出校验拒绝违规词和不符合格式的输出

* [x] AI 失败时使用 fallback_content 兜底，用户无报错感知

* [x] AI 调用日志记录 token 用量、耗时、是否成功

* [x] "换一条"每天限 1 次，第二次点击返回 429

* [x] 图文模式可切换，生成对应格式的内容

* [x] 任务生成响应时间 ≤5s（含 AI 调用）

## 数据回传与规则诊断

* [x] 数据回传 API 校验输入范围（播放量 0-1 亿，评论/私信 ≥0）

* [x] 重复回填同一任务被拒绝

* [x] 回填后自动触发规则诊断

* [x] 诊断结果正确匹配规则（play_count < 200 → hook_weak 等）

* [x] 诊断结果 API 可查询

* [x] optimization_rules 可通过后台 CRUD 配置

* [x] 24h 未回填任务显示提醒提示

## 优化任务与上线验证

* [x] 诊断后可生成下一条优化任务

* [x] 优化任务 is_optimized=true，包含 optimization_note

* [x] 优化 Prompt 包含诊断约束（如"上条钩子弱，请使用反常识型"）

* [x] 用户可看到"改了什么、为什么改"

* [x] 有未完成任务时提示"继续还是重新选择"

* [x] 结构库为空时返回友好错误提示

* [x] 48h 未回填任务自动标记 EXPIRED

* [x] 运营后台可管理结构模板、诊断规则、禁用词

* [x] 运营后台可查看用户统计和 AI 调用日志

* [x] 完整闭环端到端测试通过：选意图→拿任务→发布→回填→诊断→下一条

* [x] KPI 统计埋点就绪（内容转化率、任务执行率、次日留存率）

## 安全与合规

* [x] 匿名用户可完成完整闭环

* [x] 登录后匿名用户历史数据不丢失

* [x] 用户只能操作自己的任务（权限校验）

* [x] JWT 过期后需重新获取

* [x] AI 生成内容不包含禁用词（绝对化用语、虚假承诺）

* [ ] 手机号加密存储（待实现加密逻辑）
