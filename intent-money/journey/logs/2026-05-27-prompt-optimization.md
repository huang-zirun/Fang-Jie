# 2026-05-27 AI Prompt 优化 - 内容生成细致度提升

## 背景
用户反馈之前修改的 prompt 生成内容仍不够细致，分镜脚本描述笼统，口播文案缺乏结构化。本次优化针对短视频内容生成的三个核心模块进行细化。

## 修改内容

### 1. 分镜脚本详细度标准（5维度）

**修改文件**: `backend/app/services/ai_service.py`

将原来笼统的"具体的画面内容描述"细化为必须包含的5个维度：

| 维度 | 说明 | 示例 |
|------|------|------|
| 景别 | 远/全/中/近/特写 | 特写 |
| 角度 | 俯拍/平视/仰拍/45度 | 45度俯拍 |
| 主体动作 | 具体动作细节 | 手指缓慢按压袜底 |
| 画面焦点 | 视线集中点 | 加厚层厚度 |
| 声音配合 | 口播或字幕 | 配字幕"足弓支撑点" |

**错误示例**（优化前）：
```
特写：袜子的缓震和透气设计
```

**正确示例**（优化后）：
```
特写-45度俯拍：手指缓慢按压袜底加厚层，展示3mm厚度和回弹性，画面左侧配字幕"足弓支撑点"，背景虚化
```

### 2. 口播文案结构化（5步法）

将原来自由的"信息递进"改为严格的5步结构：

1. **痛点/场景**（1-2句）：具体人群 + 具体困扰场景，不夸张
2. **细节证据**（2-3句）：材质、设计、使用感受等可验证的具体细节
3. **体验对比**（1-2句）：使用前后的具体变化，真实不夸大
4. **判断标准**（1句）：如何选择/识别的方法，提供实用价值
5. **温和互动**（1句）：引导评论的问题，不强制私信

**新增禁用词**: 救命、神器、绝了、闭眼入、冲、秒发、必入、yyds
**推荐用词**: 舒服多了、没那么累、确实有用、可以试试、感觉不错

### 3. 钩子文案公式化

根据钩子类型提供可复制的生成公式：

| 钩子类型 | 公式 | 示例 |
|----------|------|------|
| 痛点型 | [具体人群] + [具体场景] + [反常识/悬念] | 站8小时的女生，脚疼可能不是鞋的问题 |
| 反常识 | [普遍认知] + [但是] + [具体真相] | 都说棉袜透气，但站一天脚还是闷 |
| 身份识别 | [你是] + [具体特征] + [吗/吧？] | 你的袜子是不是穿两次袜口就松了？ |
| 场景切入 | [具体时间/地点] + [具体动作] + [意外发现] | 早上找袜子翻了整个抽屉，才发现这样收才不乱 |

**约束条件**:
- 15-25字
- 必须有具体数字、场景或反常识元素
- 不得使用"一定要看""必看""震惊""绝了"等标题党词汇
- 不要承诺结果，只呈现场景或问题

### 4. 验证层加强

**修改文件**: `backend/app/services/ai_service.py` 的 `_validate_output` 函数

新增分镜详细度检查：
- 描述长度从15字提高到20字
- 必须包含景别关键词（特写/近景/中景/全景/俯拍/仰拍等）
- 必须包含动作描述（展示/拿起/对比/按压/试穿等）

## 文件变更

```
backend/app/services/ai_service.py
- _build_prompt() 函数：增加分镜5维度、口播5步法、钩子公式
- _validate_output() 函数：增加分镜详细度验证

docs/prompts.md
- 新增"内容详细度要求"完整章节
```

## 预期效果

1. **分镜脚本**：从"描述画面"升级为"指导拍摄"，创作者能直接执行
2. **口播文案**：结构清晰，信息密度适中，避免夸张表达
3. **钩子文案**：按公式生成，提高一致性和平台适配性

## 2026-05-27 二次优化

### 用户反馈
字数不够，分镜脚本需要更加细致。

### 优化内容

#### 1. 口播文案字数扩展
- **从**: 150-280字
- **到**: 250-400字
- **结构调整**：
  | 步骤 | 原字数 | 新字数 |
  |------|--------|--------|
  | 痛点/场景 | 1-2句 | 50-80字（2-3句+细节） |
  | 细节证据 | 2-3句 | 80-120字（3-4句+多维度） |
  | 体验对比 | 1-2句 | 60-80字（2-3句+时间场景） |
  | 判断标准 | 1句 | 40-60字（1-2句+参数） |
  | 温和互动 | 1句 | 20-40字 |

#### 2. 分镜脚本从5维度扩展到8维度

| 维度 | 新增 |
|------|------|
| 景别 | 增加大特写 |
| 角度 | 增加正面/侧面/背面 |
| **运镜方式** | **新增：固定/推/拉/摇/移/跟/升降** |
| **灯光设置** | **新增：自然光/柔光/侧光/逆光/顶光/补光** |
| **画面主体** | **新增：人物/手部/产品/场景，具体位置和姿态** |
| 主体动作 | 增加拉伸、翻转 |
| **道具清单** | **新增：袜/鞋/抽屉/标签/手/脚/桌/柜/盒/袋** |
| 声音/字幕 | 增加音效、字幕样式位置 |

**示例对比**：
- **优化前**：`特写-45度俯拍：手指缓慢按压袜底加厚层，展示3mm厚度和回弹性，画面左侧配字幕"足弓支撑点"，背景虚化`
- **优化后**：`特写-45度俯拍-固定机位：自然光从左侧45度打入，手指缓慢按压袜底加厚层，展示3mm厚度和回弹性，桌上放一只白袜一只黑袜做对比，画面左侧配白色字幕"足弓支撑点"，背景虚化，同期声：这里加了缓冲垫`

#### 3. 验证层加强

| 检查项 | 原标准 | 新标准 |
|--------|--------|--------|
| 分镜描述长度 | ≥20字 | **≥30字** |
| 景别检查 | 有 | 有 |
| **角度检查** | 合并 | **独立检查** |
| **运镜检查** | 无 | **新增** |
| **灯光检查** | 无 | **新增** |
| 动作检查 | 有 | 有（+拉伸/翻转） |
| **道具检查** | 无 | **新增** |
| 口播字数 | 100-350字符 | **200-500字符** |

### 文件变更

```
backend/app/services/ai_service.py
- _build_prompt() 函数：分镜8维度、口播400字、各步骤字数分配
- _validate_output() 函数：6项分镜检查、口播字数放宽

docs/prompts.md
- 更新"内容详细度要求"章节：8维度表格、口播字数表格
```

## 预期效果

1. **分镜脚本**：可直接作为拍摄指导书使用，包含运镜、灯光、道具等完整信息
2. **口播文案**：信息更丰富，细节更充分，说服力更强
3. **验证更严**：确保每个分镜都达到专业拍摄标准
