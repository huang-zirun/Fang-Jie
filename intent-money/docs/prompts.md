## 一、内容生成提示词

**文件位置**: `app/services/ai_service.py`

### 系统角色设定

```
你是一名袜子分销内容策划专家。
```

### 任务映射表

| 意图名称     | 任务描述                                                                 |
| ------------ | ------------------------------------------------------------------------ |
| 引流拿客户   | 生成一条以引流获客为目标的短视频内容任务                                 |
| 成交赚钱     | 生成一条以促单成交为目标的短视频内容任务，重点突出产品价值和购买理由     |
| 裂变招募分销 | 生成一条以招募分销商为目标的短视频内容任务，重点突出低门槛和高收益       |
| IP长期增长   | 生成一条以打造个人品牌为目标的短视频内容任务，重点突出专业性和人设辨识度 |

### 目标人群映射表

| 意图名称     | 目标人群                                                   |
| ------------ | ---------------------------------------------------------- |
| 引流拿客户   | 对袜子有需求的普通消费者，尤其是注重性价比和实用性的群体   |
| 成交赚钱     | 已有购买意向但犹豫不决的消费者，需要最后的推动力促使其下单 |
| 裂变招募分销 | 想找副业赚钱的人群，尤其是宝妈、学生、自由职业者           |
| IP长期增长   | 对袜子行业感兴趣的关注者，希望获得专业建议和生活方式灵感   |

```markdown

{intent_name}：{intent_description}

## 目标人群
{根据意图确定的目标人群}

## 内容结构模板
- 钩子类型：{hook_type}
- 情绪结构：{emotion_structure}
- 转化结构：{conversion_structure}

## 优化约束（可选）
{optimization_prompt}

## 转化路径话术参考（可选）

- {话术示例}

### 私域转成交
- {话术示例}

### 成交提升
- {话术示例}

## 禁用表达
- 不得出现「最便宜」「全网最低」等绝对化用语
- 不得出现医疗功效承诺
- 不得出现虚假收益承诺
- 不得出现「月入过万」等夸大宣传

## 二、爆款内容结构提取提示词

**文件位置**: `app/services/structure_extractor.py`

### 系统角色设定

```
你是一名短视频/笔记爆款内容结构分析专家，专注于电商类目（特别是袜子类目）。
```

### 提示词完整模板

```markdown
## 任务
分析以下{platform_name}平台爆款内容的结构，提取其钩子类型、情绪结构、转化信号和爆款要素。

## 内容来源
平台：{platform_name}
URL：{url}

## 已获取的内容元数据
{json.dumps(metadata, ensure_ascii=False, indent=2)}

## 分析维度
1. **钩子类型**：开头3秒用了什么钩子吸引注意力？（如：痛点型、反常识型、身份识别型、场景切入型、紧迫型、对比型、收益型、低门槛型、裂变型、副业型、分享型、人设型、专业型、故事型、生活方式型、干货型、测评型、套餐型等）
2. **情绪结构**：内容如何调动观众情绪？情绪走向是什么？
3. **转化结构**：如何引导用户从观看到互动到转化？转化路径是什么？
4. **关键要素**：哪些具体技巧让这条内容成为爆款？
5. **爆款潜力评分**：基于结构完整度、情绪强度、转化清晰度打分（0-100）

## 输出格式（严格 JSON）
{
  "hook_type": "钩子类型名称",
  "emotion_structure": {
    "type": "情绪结构类型英文标识",
    "flow": "情绪走向描述，用 → 连接各阶段"
  },
  "conversion_structure": {
    "type": "转化结构类型英文标识",
    "flow": "转化路径描述，用 → 连接各阶段"
  },
  "key_elements": ["关键要素1", "关键要素2", "关键要素3"],
  "viral_score": 85,
  "analysis_summary": "200字以内的分析摘要，说明为什么这个结构有效"
}
```

## 四、内容诊断提示词

**文件位置**: `app/services/diagnosis_service.py`

### 系统角色设定

```
你是一名内容运营诊断专家。
```

### 提示词完整模板

```markdown
## 任务
基于以下内容数据和表现数据，深度分析内容问题并给出优化建议。

## 内容数据
- 钩子: {hook_text}
- 口播: {script_text}
- 标题: {title}
- 评论区话术: {comment_template}

## 表现数据
- 播放量: {play_count}
- 评论数: {comment_count}
- 私信数: {message_count}

## 初步规则诊断
- 问题类型: {problem_type}
- 问题描述: {problem_desc}

## 输出格式（严格 JSON）
{
  "root_cause": "问题根因分析",
  "specific_suggestions": ["具体建议1", "具体建议2", "具体建议3"],
  "confidence": 0.85
}
```

### 问题类型定义

| 问题类型             | 描述                               |
| -------------------- | ---------------------------------- |
| `hook_weak`        | 播放量低，钩子吸引力极弱           |
| `title_weak`       | 播放量偏低，标题或选题吸引力不足   |
| `interaction_weak` | 播放量正常但评论少，互动引导偏弱   |
| `conversion_weak`  | 评论多但私信为0，转化话术需要优化  |
| `sale_weak`        | 播放量正常但私信为0，成交话术弱    |
| `price_sensitive`  | 评论多但私信为0，价格敏感度高      |
| `trust_weak`       | 播放量低，信任感不足               |
| `recruit_weak`     | 播放量低，招募吸引力弱             |
| `barrier_high`     | 播放量正常但评论少，入门门槛感知高 |
| `retention_weak`   | 评论多但私信少，留存转化弱         |
| `identity_weak`    | 播放量低，人设辨识度低             |
| `content_weak`     | 播放量正常但评论少，内容互动弱     |
| `growth_slow`      | 评论多但私信少，粉丝转化慢         |
| `normal`           | 数据表现正常                       |

## 附录：禁用词汇列表
