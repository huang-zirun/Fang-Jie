# Product Requirements Document: 意图选择式赚钱系统（Intent-based Money OS）

**版本**: 1.0\
**日期**: 2026-05-20

***

## 执行摘要

本系统是一款面向袜子分销商的"一键赚钱执行系统"。用户只需选择一个赚钱目标（如引流、成交、裂变），系统自动基于实时爆款数据生成唯一可执行内容任务，用户发布后系统抓取数据并持续优化下一条内容，形成"选择→执行→反馈→优化"的完整变现闭环。

系统的核心价值不是AI内容生成工具，而是**替用户做运营决策的赚钱执行系统**——把复杂的运营判断压缩成一个按钮，让零经验的分销商也能持续产出有转化力的内容。

***

## 问题陈述

**当前痛点**：分销商（尤其是新手、宝妈、副业人群）面临三重障碍：

1. 不知道发什么内容（决策成本高）
2. 不知道怎么拍才能卖货（执行能力弱）
3. 发了没效果不知道怎么改（优化能力缺失）

**解决方案**：用户只做一个选择，系统接管所有运营决策——选平台、选结构、写脚本、做优化、给下一条。

**商业影响**：提升分销商内容转化率（流量→成交），降低用户流失，形成平台粘性与口碑裂变。

***

## 成功指标

**核心KPI**：

- **内容转化率**：用户发布内容后产生私信/成交的比例，目标 MVP 阶段达到 ≥15%
- **任务执行率**：用户点击"我已发布"的比例，目标 ≥60%
- **次日留存率**：用户第二天继续使用系统的比例，目标 ≥40%

**验证方式**：上线后第4周开始统计，以自然周为单位追踪以上三项指标。

***

## 用户画像

### 主要用户 A：新手分销商

- **角色**：刚加入袜子分销，无内容创作经验
- **目标**：快速出单，证明自己能赚钱
- **痛点**：完全不知道从哪里开始，害怕拍视频
- **技术水平**：初级，需要手把手引导

### 主要用户 B：有经验分销商

- **角色**：已有一定粉丝基础，但内容效率低
- **目标**：提升出单频率，减少无效内容
- **痛点**：凭感觉发内容，不知道哪种结构更有效
- **技术水平**：中级

### 次要用户 C：全职内容创作者

- **角色**：多账号运营，追求规模化出单
- **目标**：批量生产高转化内容，降低单条内容制作成本
- **技术水平**：高级

### 次要用户 D：兼职宝妈/副业人群

- **角色**：时间碎片化，每天只有1-2小时
- **目标**：低时间投入，稳定副业收入
- **痛点**：没时间研究平台规则和内容策略
- **技术水平**：初级

## 用户故事与验收标准

### Story 1：意图选择

**作为** 新手分销商\
**我想要** 进入系统后只看到简单的目标选项\
**以便** 不需要思考就能开始行动

**验收标准**：

- [ ] 首屏只展示4个意图按钮，无其他干扰元素
- [ ] 按钮文案是"赚钱目标"语言，不是功能描述语言
- [ ] 点击任意按钮后，2秒内进入任务界面
- [ ] 不需要注册/填写任何信息即可完成首次选择

### Story 2：获取唯一任务

**作为** 分销商\
**我想要** 点击意图后系统直接给我今天要做的一件事\
**以便** 不需要自己想内容，照做就行

**验收标准**：

- [ ] 系统生成的任务包含：3秒钩子、分镜脚本、口播文案、标题、评论区话术
- [ ] 任务界面只有一个主操作按钮："我已发布"
- [ ] 系统在任务界面顶部显示一句话说明"为什么这条内容能赚钱"
- [ ] 内容结构基于当前平台（抖音/小红书）的实时爆款数据生成

### Story 3：发布确认与数据追踪

**作为** 分销商\
**我想要** 点击"我已发布"后系统自动追踪内容表现\
**以便** 不需要自己分析数据

**验收标准**：

- [ ] 点击"我已发布"后，系统显示"正在追踪你的内容表现"状态
- [ ] 系统在发布后24小时内抓取：播放量、完播率、评论数、私信数
- [ ] 数据达到判断阈值后，系统主动推送优化后的下一条任务
- [ ] 若24小时内无数据回传，系统提示用户手动输入关键数据

### Story 4：系统优化下一条

**作为** 分销商\
**我想要** 系统根据上一条内容的表现自动给我优化版本\
**以便** 越做越好，不走弯路

**验收标准**：

- [ ] 系统展示上一条内容的简要诊断（如"钩子弱，完播率低"）
- [ ] 新任务明确标注"已针对上次问题优化"
- [ ] 优化逻辑可追溯：用户可看到"改了什么、为什么改"

## 功能需求

### 核心功能一：意图选择首屏

**描述**：用户进入系统的唯一入口，4个赚钱目标按钮。

**MVP包含的4个意图**：

1. 引流拿客户 → 我想让更多人看到我
2. 成交赚钱 → 我想卖出更多袜子
3. 裂变招募分销 → 我想让别人帮我赚钱
4. IP长期增长 → 我想做账号做品牌

**用户流程**：进入App → 看到4个按钮 → 点击目标 → 进入任务界面

**边界情况**：

- 用户未绑定平台账号时：引导绑定，或允许先体验再绑定
- 用户当天已有未完成任务：提示"你还有一个任务未完成，继续还是重新选择？"

### 核心功能二：唯一任务界面

**描述**：系统生成的今日唯一可执行内容任务。

**任务内容结构**：

```
平台标签（抖音/小红书）
今日任务标题
─────────────────
3秒钩子文案
分镜脚本（3-5个镜头描述）
口播文案（完整台词）
发布标题（含话题标签）
评论区置顶话术
─────────────────
[我已发布] 按钮
```

**边界情况**：

- 用户觉得内容不合适：提供"换一条"选项（每天限用1次）
- 用户没有拍摄设备：提供图文版替代方案

### 核心功能三：后台四大引擎

#### 3.1 爆款结构引擎

- 输入：产品类型（袜子）、目标人群、平台
- 处理：从结构库中匹配当前最优内容结构
- 输出：钩子类型 + 情绪结构 + 转化结构的组合方案
- 结构库包含：钩子库（痛点型/反常识/身份识别/场景切入）、情绪结构库、转化结构库

#### 3.2 实时数据引擎

- 数据来源：抖音同类爆款、小红书热帖（通过平台API或爬虫）
- 提取维度：内容结构、转化信号（评论关键词）、用户反馈
- 输出：当前最优结构TOP3，每日更新

#### 3.3 转化路径引擎

- 三段转化链：公域→私域（评论引导话术）→私域→成交（破冰+套餐推荐）→成交提升（催单逻辑）
- 根据用户选择的意图，自动匹配对应转化路径

#### 3.4 学习进化引擎

- 输入：视频表现数据、用户成交反馈
- 分析：判断问题类型（钩子弱/人群错/转化弱/信任不足）
- 输出：下一条内容的优化版本 + 诊断说明

### 不在本期范围内

- 自动剪辑/视频生成功能
- 多产品品类支持（本期仅袜子）
- 投放/付费推广功能
- 团队/多账号管理
- 视频号平台支持

## 技术约束

### 性能

- 任务生成响应时间：用户点击意图后 ≤3秒完成内容生成
- 数据抓取频率：每日更新一次爆款结构库
- 系统可用性：≥99%（核心任务生成链路）

### 安全与合规

- 用户平台账号授权：仅读取数据权限，不代替用户发布内容
- 数据存储：用户内容数据本地加密存储，不对外共享
- 平台合规：遵守抖音/小红书开放平台使用条款，避免违规爬取

### 集成依赖

- **抖音开放平台**：获取视频数据（播放、完播、评论）
- **小红书开放平台**：获取笔记数据（阅读、点赞、评论）
- **AI内容生成**：Claude API（用于脚本生成和内容优化）

### 技术栈约束

- 移动端优先（iOS + Android）
- 支持微信内嵌H5（考虑到分销商微信生态）

## MVP范围与分期

### Phase 1：MVP（首批上线）

**平台**：抖音 + 小红书\
**意图**：引流拿客户（最高频需求）\
**核心功能**：

- 意图选择首屏（仅"引流拿客户"可用，其余灰显）
- 唯一任务界面（含完整内容结构）
- "我已发布"确认流程
- 基础数据回传（手动输入播放量/评论数）
- 简单优化逻辑（基于规则，非AI）

**MVP定义**：用户能完成"选目标→拿任务→发内容→看反馈"完整闭环。

### Phase 2：增强（MVP验证后）

- 开放全部4个意图
- 接入平台API自动抓取数据
- AI驱动的学习进化引擎
- 转化路径引擎（私信话术、成交话术）

### Phase 3：规模化

- 多产品品类支持
- 全职创作者批量任务模式
- 分销团队管理功能
- 投放效果追踪

## 风险评估

| 风险           | 概率 | 影响 | 缓解策略                   |
| ------------ | -- | -- | ---------------------- |
| 平台API限制/封禁   | 高  | 高  | MVP阶段用手动输入数据替代，降低API依赖 |
| 内容结构库质量不足    | 中  | 高  | 上线前人工验证50+爆款结构，持续迭代    |
| 用户执行率低（不愿发布） | 中  | 高  | 降低发布门槛，提供图文替代方案        |
| AI生成内容质量不稳定  | 中  | 中  | 设置人工审核兜底，用户可"换一条"      |
| 平台规则变化导致内容失效 | 低  | 中  | 结构库每日更新，快速响应平台变化       |
